Everything under the folder is sent. Files that are not run history are ignored, so pointing this at saves is enough.

Browsers send each file's path relative to the folder you pick, so modded is only detected when you select at or above the folder containing it. Picking a saves folder inside modded/ looks identical to a vanilla one, so tick the box.

Where are my saves?

macOS

~/Library/Application Support/SlayTheSpire2/steam/<id>/profile1/saves

Selecting steam/<id> instead picks up every profile at once, vanilla and modded, each tagged correctly.

Uploading the same run twice is harmless: runs are matched on their start time and skipped.

The game only keeps its last 100 runs, so anything older than that is already gone unless you have archived it.
